# Project scope

Status: Source-backed study scope; proposed workflows are not implementation claims.  
Last reviewed: 2026-10-19.

ACCS is a web-based discussion forum and student-support prototype for QCU Main Campus College of Computer Studies, covering Information Technology, Computer Science, and Information Systems. Planned areas include discussion, announcements, consultations, evaluations, role-based views, grievance routing and milestones, and an AI assistant. The module inventory describes ten operational roles. These features are requirements to evaluate, not proof of completed services.

The latest paper specifies simulated enrollment lists, sample records, and frontend state management. It excludes direct connections to live university databases and automatic synchronization. The current code has a React frontend shell and an Express health endpoint; no application database or AI provider is configured.

Before institutional records or AI processing of confidential content, the team needs approved role permissions, privacy and retention rules, routing and escalation policy, provider data handling, authentication, audit, and backups. The older proposal describes broader workflows; where it conflicts with the newer paper's prototype limits, the newer paper governs this vault until the team approves a revision.
